# Portafolio de Kenneth Mejia

Sitio web personal con mi presentación, habilidades y proyectos.

## Estructura

```
mi-portafolio/
├── index.html    ← Página principal
├── styles.css    ← Estilos
├── README.md     ← Descripción del proyecto
└── foto.jpg      ← (agrega tu foto aquí)
```

## Cómo verlo

Abre `index.html` en el navegador. No necesita instalación.

## Cómo personalizarlo

1. **Foto:** guarda tu foto como `foto.jpg` junto a `index.html`. Mientras no exista, se muestran las iniciales "KM".
2. **Proyectos:** en `index.html`, dentro de la sección `#proyectos`, edita cada bloque `<li class="project">` con el nombre, la descripción, las tecnologías y el enlace de tu repositorio.
3. **Habilidades:** en la sección `#habilidades`, agrega o quita elementos `<li>`.
4. **Colores:** cambia las variables al inicio de `styles.css` (`--void`, `--bone`, `--soul`, `--geo`).

## Publicarlo gratis con GitHub Pages

1. Sube la carpeta a un repositorio llamado `mi-portafolio`.
2. En GitHub: **Settings → Pages → Deploy from a branch → main / root**.
3. Tu sitio quedará en `https://kendev2105.github.io/mi-portafolio/`.

## Tecnologías

HTML5 y CSS3, sin librerías externas (solo las tipografías Cinzel y Cormorant Garamond de Google Fonts).

## Estilo

Inspirado en la atmósfera de Hollow Knight: fondo de vacío oscuro, tipografía clásica en mayúsculas, brillo azulado de "alma", marco en arco para la foto y máscaras como adorno de la barra superior. Todo está hecho con CSS y SVG propios; no usa imágenes ni recursos del juego.
